Come richiedere un preventivo

Invia foto o disegno, misure, quantità e, se li hai, i file del logo o dei testi. Il preventivo indica lavorazione, costi e tempi. Trovi il metodo completo in come lavoriamo e le indicazioni sui file in preparare il file per il laser.

Hai un oggetto, un logo o una serie da personalizzare?

Mandaci una foto del pezzo, le misure, la quantità e il file grafico. Verifichiamo materiale e area lavorabile prima di confermare il preventivo.
